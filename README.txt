# EventOps Copilot communication prototype

This is a static clickable prototype for the Week 2 communications assignment.

What it demonstrates

1. One verified operational change with four fixed fields
2. Four audience-specific messages for the C-Suite, Event Lead, Host, and Guest
3. Source traceability
4. A human challenge path
5. A visible employee feedback loop
6. The four-phase pilot rollout

How to open it

Double-click index.html.

No API keys are required. The prototype does not call OpenAI, Claude, Gemini, Hugging Face, or any other model. All example outputs are prewritten for the prototype.

How to put it online with Vercel

1. Go to vercel.com and sign in
2. Create a new project
3. Upload the folder or connect a GitHub repository containing index.html
4. Accept the default static-site settings
5. Deploy
6. Copy the public URL into your portfolio or assignment if your professor allows links

Because this prototype is static, it does not consume AI inference credits when people click through it.
